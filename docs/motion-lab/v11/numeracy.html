수리 · 11차 시안

기업분석과 재무학에서 자주 쓰는 계산을 일곱 분야로 나눠, 분야마다 같은 수준의 문제를 날마다 새로 만들어 냅니다. 푼 문제는 저장하지 않고, 분야별로 한 세트를 마칠 때마다 정답 수, 중앙값 시간, 가장 빠른 시간만 남겨 시간이 얼마나 줄었는지 봅니다.

홈의 수리 줄이나 이어서 하기로 들어가 직접 풀어 보세요. 위 막대의 정답 넣기는 지금 문제의 정답을 대신 눌러 줍니다. 기록은 이 브라우저에만 남고, 처음 열 때 3주치 예시 기록을 심어 둡니다.

분야 일곱

분야별 예시 문제 (생성기가 지금 만든 것)

채점

  • 정확한 값: 나누어떨어지게 만든 문제. 값이 같으면 정답(쉼표, 띄어쓰기, 뒤의 0은 상관없음).
  • 반올림: 문제 아래에 "반올림해 소수 첫째 자리까지"처럼 자리를 적습니다. 반올림 자리에서 0.5 경계에 가까운 문제는 만들지 않습니다(계산 순서에 따라 답이 갈리지 않게).
  • 어림: 어림셈과 일부 복리 문제. "실제 값의 ±5% 안"처럼 허용 범위를 적고 그 안이면 정답.
  • 끊어 쓰기: 큰 수 읽기는 값만이 아니라 모양까지 봅니다. 31232342만 5321은 값은 같지만 오답이고 "만 단위 아래는 네 자리까지 끊어 써요"가 뜹니다.
  • 틀렸을 때 이유를 하나 더 알려 줍니다: 부호가 반대, 반올림 자리, 자릿수(10의 거듭제곱만큼 다름).
  • 시간은 문제가 다 들어온 순간부터 확인을 누를 때까지. 세트의 중앙값과 최고 기록은 맞힌 문제의 시간만 씁니다. 빨리 찍고 틀린 문제가 기록을 당기지 않게 하려는 것입니다.

수준 규칙

  • 분야마다 수준 1에서 4. 수준마다 문제 유형 여섯 개가 고정이고 순서와 숫자만 바뀝니다. 그래서 같은 수준 안의 세트끼리는 시간을 견줄 수 있습니다.
  • 올림: 지금 수준에서 3세트 이상 했고, 최근 3세트 정답률 90% 이상, 최근 3세트 중앙값들의 중앙값이 목표 시간 이하.
  • 내림: 최근 2세트가 모두 정답률 60% 미만. 시간이 느린 것만으로는 내리지 않습니다.
  • 유지: 그 밖의 모든 경우. 수준이 바뀌면 그 수준의 기록을 새로 셉니다(최고 기록도 수준마다 따로).
  • 목표 시간은 처음 정한 값입니다. 2주 써 본 실제 중앙값을 보고 고치는 것을 권합니다.

기록 모양

문제와 답은 남기지 않습니다. 같은 씨앗(날짜와 분야)이면 같은 문제가 다시 만들어지므로, 필요하면 언제든 다시 볼 수 있습니다.

numeracy: {
  v: 1,
  level: { read: 2, fx: 1, ratio: 1, ... },
  sessions: [
    { d: "2026-11-21", k: "fx", lv: 2,
      n: 6, ok: 5, med: 11.2, best: 7.4, sum: 74.3 }
  ]
}
  • 세트 한 줄이 약 70바이트. 하루 2줄이면 1년에 50KB 정도라 지우지 않아도 됩니다.
  • 추이 그림은 날짜마다 중앙값의 중앙값 하나를 점으로, 수준이 바뀐 자리에 세로 점선과 수준 이름을 둡니다. 주황 점은 지금 수준의 최고 기록.
  • 앱에 넣을 때는 src/types.ts 의 개인 기록에 numeracy 를 더하고, 읽고 쓰기는 src/store.tsx 에만 둡니다. 내보내기에 함께 들어갑니다.

하루 할당 제안

  • 하루 한 세트, 두 분야 × 6문제 = 12문제, 약 3분. 분야는 날짜로 정해 이틀씩 돌아가며, 한 주에 분야마다 정확히 두 번 나옵니다(추이 점이 주 2개씩 쌓입니다).
  • 한 분야를 이어서 6문제 푼 뒤 다음 분야로 넘어갑니다. 섞어 내면 분야를 바꾸는 시간까지 재게 되어 기록이 흐려집니다.
  • 더 하고 싶으면 분야 줄을 눌러 그 분야만 6문제(추가 학습). 하루 목표에는 넣지 않고 기록에는 남깁니다.
  • 홈 오늘 카드에 네 번째 줄로 "수리 0/12"를 둡니다. 다른 과제처럼 그날 안에 끝내면 채워집니다.

정해 주실 것

  1. 연속 기록에 넣을지. 제안: 넣는다(하루 목표 = 뉴스, 영단어, Latticework, 수리). 대신 처음 2주는 넣지 않고 써 본 뒤 정하는 방법도 있습니다.
  2. 하루 양. 두 분야 12문제(제안), 또는 한 분야 6문제(약 1분 30초), 또는 시간 3분 고정(문제 수가 바뀌어 비교가 어려워짐).
  3. 분야 목록. 일곱 가운데 빼거나 더할 것. 예: 회계 항등식(자산 = 부채 + 자본) 검산, 희석 주식 수.
  4. 목표 시간. 지금 값으로 시작하고 2주 뒤 실제 기록으로 고칠지.
  5. 환율 수준. 지금은 1달러 1,300원에서 1,480원, 100엔 880원에서 990원 사이를 무작위로 씁니다. 그날 실제 환율을 아침 작업이 넣어 주는 방법도 있습니다(문제는 그대로 생성).
