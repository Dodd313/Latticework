Latti · 8차

앱이 직접 말을 건넵니다. 손그림 마스코트 대신 앱 아이콘의 3x3 칸이 그대로 Latti 가 됩니다. 칸이 깜빡이고, 물결치고, 숨을 죽이고, 잠듭니다. 말은 말풍선 한 줄, 실제 숫자와 실제 이름만 씁니다. 같은 Latti 가 지식 그래프의 한가운데에 있습니다.

폰을 누르면 다음 장면으로 넘어갑니다. 위 막대의 "다시 말하기" 를 여러 번 눌러 같은 순간에도 말이 바뀌는 것을 보세요.

페르소나

표정

칸만 움직입니다. 600ms 안에 끝나고 다시 가만히 있습니다. 계속 흔들리는 움직임은 없습니다. 동작 줄이기 설정에서는 움직이지 않고 모습만 바뀝니다. 아래 표식을 누르면 다시 움직입니다.

말투

  • 해요체, 한 줄 22자 안. 느낌표는 한 줄에 하나까지. 긴 줄표, 화살표, 이모지 없음.
  • 숫자는 모두 실제 값. 이름도 실제로 배운 개념, 실제 오늘 기사.
  • 칭찬은 결과보다 노력. 틀렸을 때도 "괜찮아요" 쪽. 재촉과 죄책감 없음. 쉬다 돌아오면 반가워할 뿐 빠진 날을 세지 않습니다.
  • 화면 설명 없음. "~를 누르면", "막대는 ~예요" 같은 줄은 검사에서 걸러집니다.
  • "더 풀기" 는 쓰지 않습니다. "추가 학습".

매번 다른 말이 나오는 구조

앱은 서버 없는 정적 사이트(GitHub Pages)이고 아이폰 홈 화면 웹앱으로 씁니다. 화면에서 바로 LLM 을 부르면 API 키가 그대로 드러나므로, 말을 만드는 일과 고르는 일을 나눕니다.

층무엇어떻게
1. 오늘 문구아침 예약 작업(Claude)이 feed.json 을 쓸 때 docs/data/latti.json 도 함께 씀그날 기사 이름, 숫자, 최근 배운 개념을 넣은 20줄 안팎. 날짜가 지나면 저절로 빠짐. 고를 때 무게 3배
2. 상시 문구저장소의 문구 뱅크. 지금 줄{streak}, {concept|을} 같은 빈칸이 있는 틀. Claude 가 가끔 몇 줄씩 보탬
3. 기기에서 고르기Latti.lines.pick(상황, ctx)상황과 숫자 조건이 맞는 줄만 남기고, 가장 눈에 띄는 사실(단계 p)을 70%, 한 단계 아래를 30%로 섞어 무게대로 뽑음. 3일 안에 보인 줄은 빼고, 빈칸을 채운 뒤 22자를 넘으면 버림. 조사는 앞말 받침을 보고 고름(을/를, 이/가, 은/는, 과/와, 으로/로)
4. 나중에작은 서버 함수 하나(Cloudflare Workers 등)가 키를 숨기고 LLM 을 부름그 순간의 숫자로 한 줄을 새로 씀. 같은 검사를 통과한 줄만 쓰고, 실패하면 2, 3층으로 돌아감
방식좋은 점아쉬운 점
아침 작업 + 뱅크 (권장)비용 없음, 키 노출 없음, 오프라인에서도 말함, 오늘 기사를 이름으로 부를 수 있음, 검사 후에만 나감하루 중 새로 생긴 일(방금 배운 개념)은 빈칸 틀로만 말함
화면에서 LLM 직접가장 유연함키가 드러남. 불가
서버 함수 + LLM그 순간에 꼭 맞는 말서버 운영, 비용, 느린 응답(말풍선이 늦게 뜸), 검사를 통과 못 하는 줄 처리

아침 작업은 새 줄을 쓴 뒤 require('latti.js').lines.lint(text) 로 검사합니다. 22자, 해요체 끝맺음, 금지어, 줄표, 화살표, 느낌표 두 개, 화면 설명, 죄책감 말투를 봅니다. 지금 뱅크와 오늘 문구 모두 통과합니다.

아직 확인하지 못한 것

  • 아침 예약 작업에 latti.json 쓰기를 붙이지 않았습니다. 작업 지시문을 고쳐야 하고, 실제로 하루 20줄을 매일 검사 통과하게 쓰는지는 며칠 돌려 봐야 압니다.
  • "3일 안에 반복 없음" 은 기기의 localStorage 에 기록합니다. 아이폰 홈 화면 웹앱에서 이 기록이 오래 유지되는지는 확인하지 않았습니다. 지워져도 말이 조금 겹칠 뿐 깨지지는 않습니다.
  • 영어 이름 뒤 조사는 어림값입니다(WACC 처럼 읽는 소리가 다른 이름은 ctx 에 읽는 소리를 함께 넣어야 함). 그래서 영단어 빈칸 뒤에는 조사를 붙이지 않는 틀만 씁니다.
  • 사용자가 정말로 "정해진 문구" 라고 눈치채지 못하는지는 몇 주 써 봐야 압니다. 뱅크 크기와 반복 금지 날짜를 그때 조정합니다.
