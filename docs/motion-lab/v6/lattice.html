지식 탭 · 격자 지도

뉴스, 단어, 개념을 영역별 격자로 놓았습니다. 칸 하나가 항목 하나입니다. 칸은 처음 본 날 순서로 왼쪽 위에서 오른쪽 아래로 놓이므로, 격자의 끝이 가장 최근에 배운 것입니다.

읽는 법 (화면에는 쓰지 않음)

모양뜻
칸의 색영역. 뉴스 blue, 단어 purple, 개념 green
칸의 진하기반복 횟수. 1회 100, 2회 200, 3~4회 300, 5~7회 500, 8회 이상 700 단계
속이 빈 칸기억이 90% 아래로 내려간 항목(복습할 것). 테두리 색은 반복 단계를 따른다
칸 크기개념 칸이 단어·뉴스 칸보다 크다. 이 앱의 중심이 개념이기 때문
카드 오른쪽 숫자기억 중 / 전체. 뉴스는 기억 모델이 없어 전체만
위 세 칸전체, 오늘(오늘 처음 보거나 복습한 것), 복습. 오늘과 복습은 누르면 해당 칸만 남기고 나머지를 흐리게 한다. 뉴스·단어·개념 수는 각 카드 오른쪽에 이미 있어서, 위 칸에 다시 두지 않았다(중복 제거)

움직임

  • 들어올 때: 카드마다 칸이 왼쪽 위에서 대각선으로 차오른다(칸당 16ms 간격, 380ms). 칸 순서가 곧 날짜 순서라서 물결이 공부한 시간을 다시 훑는 셈이다. 카드는 화면에 들어올 때 한 번만 채워진다.
  • 칸 누르기: 그 항목과 연결된 칸만 남고 나머지는 흐려진다. 기사에 나온 개념, 개념의 용어인 단어, 같은 주제의 개념이 영역을 넘어 함께 켜진다. 아래 카드의 연결 칩을 누르면 그 항목으로 건너간다. 옵시디언 그래프의 "이웃 강조"를 격자 위에서 한다.
  • 복습: 빈 칸 안에서 색이 가운데부터 차오르고(340ms), 칸이 한 번 튀고(Toss quick, bounce 스프링), 테두리 하나가 퍼지며 사라진다. 카드의 숫자는 올라가고 위의 복습 수는 내려간다.
  • 세션 끝: 복습 세션을 마치고 이 탭으로 오면, 푼 개념들이 110ms 간격으로 차례로 채워진다.

빌려 온 것

  • GitHub 기여 그래프: 둥근 사각 칸, 단계별 색, 시간 순서의 배치.
  • 주기율표: 행 앞의 묶음 이름(주제, 단어장, 달), 묶음마다 길이가 다른 행.
  • 옵시디언 그래프 뷰: 노드를 누르면 이웃만 남기는 강조와 링크를 따라가는 탐색.
  • Apple 피트니스 링: "채워야 할 빈 것"을 속이 빈 모양으로 보여 주는 방식.
  • Latticework 아이콘: 둥근 흰 사각 격자. 탭 아이콘도 같은 격자다.

장점

  • 186개 항목이 스크롤 두 번 안에 전부 보인다. 그래프 뷰처럼 확대·이동할 필요가 없다.
  • 빈 칸의 양이 곧 복습할 양이라 한눈에 "어디가 비었는지" 보인다. 범례 없이도 채우고 싶어지는 모양이다.
  • 칸 위치가 고정이라 날마다 같은 자리에서 같은 항목을 찾는다. 공간 기억이 생긴다.
  • 앱 아이콘, 홈 카드, 기록 탭과 같은 언어(흰 카드, 둥근 사각, Toss 색)라 따로 놀지 않는다.

약점 (솔직하게)

  • 연결이 상시 보이지 않는다. 칸을 눌러야 영역을 넘는 연결이 드러난다. "지식이 엮인다"는 느낌은 그래프 뷰보다 약하다.
  • 단어·뉴스 칸이 18px 안팎이라 손가락으로 정확히 누르기 어렵다. 실제 앱에서는 길게 눌러 끌면 칸을 훑는 돋보기가 필요하다.
  • 항목이 천 개를 넘으면 토익 단어장 하나가 화면을 다 차지한다. 그때는 단어장별로 접거나, 반복 단계별로 묶어 "칸 하나 = 열 단어"로 바꿔야 한다.
  • 뉴스는 복습이 없어서 칸이 다 차 있고 숫자도 하나뿐이다. 다른 두 카드와 결이 다르다.
  • "진하기 = 반복 횟수"는 처음 보는 사람이 바로 읽지 못한다. 대신 같은 칸이 날마다 진해지는 걸 보며 배우게 된다.

실제 앱에 필요한 데이터

  • 항목마다 처음 본 날, 마지막 복습 날, 반복 횟수, 기억 유지 일수(FSRS의 stability). 지금 앱은 정답 여부만 저장하므로 복습 기록 표를 새로 둬야 한다.
  • 개념의 분야·주제, 단어의 단어장, 기사의 날짜. 이미 있는 값이다.
  • 연결: 기사에 나온 개념(기사 요약 생성 때 함께 뽑기), 개념의 용어인 단어, 같은 주제의 개념.
  • "오늘" 칸을 위한 오늘 처음 본 것·오늘 복습한 것 목록.
  • 이 시안의 반복·기억 값은 고정 시드로 만든 예시다. 항목 이름과 묶음은 실제 앱 데이터다.
